SNYK-GOLANG-GITHUBCOMAWSAWSSDKGOV2SERVICECLOUDWATCHLOGS-16316406 | aws-sdk-go-v2 CloudWatch Logs | CVSS 8.2 | High | no CVE assigned
What: An uncaught exception in the EventStream decoder crashes the host process
when it receives a crafted EventStream response containing an invalid header
value type byte outside the valid range. Snyk records the fix as 1.65.0.
For cyber-dojo: the package is linked into dockerd, which uses it for the awslogs
logging driver. A crafted response has to arrive over the TLS-protected
CloudWatch endpoint, so exploiting it requires a MITM position on that
connection. User code runs with --net=none and cannot interact with the
CloudWatch connection at all. The impact is availability only; the decoder crash
cannot disclose or alter data.
Verdict: Not exploitable by user code. DoS-only; requires MITM of a TLS
CloudWatch endpoint.
Note: dockerd in this image vendors cloudwatchlogs v1.80.0, above the recorded
fix, yet snyk still reports this vuln. The verdict above does not rest on the
vendored version, so the entry stays until snyk stops reporting it.
